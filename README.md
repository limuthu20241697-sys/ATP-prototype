# Void landing page

A one-page website for Void, a platform for finding and booking live events in Sri Lanka.

## What we're using

- HTML for the pages
- CSS for the styling
- JavaScript for the interactive parts

No frameworks and no build step.

## How to run it

Serve this folder with any static server, then open `http://localhost:8000`:

```
python -m http.server
```
