# 3D assets

Used by the fans' realistic 3D view (`venue3d/realism.js`). All from [Poly Haven](https://polyhaven.com), CC0 (free to use, no credit required).

| File | Poly Haven asset | What it's for |
|---|---|---|
| `sky_day_2k.hdr` | kloofendal_48d_partly_cloudy_puresky (2k) | The daytime sky and the light that bounces off everything |
| `leafy_grass_*_1k.jpg` | leafy_grass (1k: colour, normal, roughness) | Lawns |
| `concrete_pavement_*_1k.jpg` | concrete_pavement (1k) | The event floors, plazas and paths |
| `asphalt_02_*_1k.jpg` | asphalt_02 (1k) | Roads and city streets |

The trees, palms, people, Lotus Tower, theatre and city are built in code (no model files).
